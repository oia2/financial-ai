# Задание на правку дизайна в Open Design

**Проект**: «Портфель FINANCIAL AI» (`financial-ai-portfolio.html`, `brand-spec.md`)
**Причина**: сессия уточнений спецификации 2026-08-26 изменила объём фичи; утверждённый
дизайн больше не покрывает два требования и содержит элементы, выведенные из объёма.
**Основание**: Принцип III Constitution — исходный артефакт правится до реализации.

Текст ниже — готовый промт. Скопировать целиком в Open Design для проекта
«Портфель FINANCIAL AI».

---

Обнови дизайн раздела «Портфель» проекта «Портфель FINANCIAL AI». Изменения продиктованы
уточнением требований: доступ к брокеру теперь конфигурируется на стороне сервера, а не
подключается пользователем, добавлены автообновление с настраиваемым интервалом и
отдельное состояние обрыва связи с сервером.

Сохрани без изменений: существующую композицию экрана, сетку, порядок и состав сводных
показателей, таблицу позиций, типографику и цветовые токены из `brand-spec.md`
(`--bg`, `--surface`, `--fg`, `--muted`, `--border`, `--accent`), плотную типографическую
иерархию и моноширинный ритм числовых значений. Новые элементы должны выглядеть как часть
той же системы: тонкие границы, радиусы 8–16 px, синий — редкий высокосигнальный акцент.

## 1. Добавь настройку интервала автообновления

Данные счёта обновляются автоматически в фоне, и пользователь управляет частотой.

- Поле ввода целого числа **секунд** (не выпадающий список): значение по умолчанию **60**,
  допустимый диапазон **15–3600**. Диапазон должен быть виден пользователю как подсказка,
  а не только в сообщении об ошибке.
- Состояние ошибки валидации: значение вне диапазона или не целое число. Покажи
  сообщение, объясняющее допустимый диапазон, и визуально отметь поле. Прежнее значение
  при этом продолжает действовать — это должно быть понятно из формулировки.
- Рядом с данными портфеля должно быть видно **действующий** интервал обновления, чтобы
  пользователь понимал, с какой частотой обновляются цифры.

Предпочтительное размещение — в меню счёта (`account-menu`), под действием
«Обновить данные», на месте удаляемого пункта «Отключить брокера». Если по композиции
уместнее вынести настройку в шапку рядом с блоком «Актуальность» — предложи этот вариант
как альтернативу и покажи оба.

## 2. Добавь состояние «Нет связи с сервером Financial AI»

Сейчас в дизайне шесть состояний раздела: загрузка, брокер не подключён, портфель пуст,
данные актуальны, данные устарели, ошибка синхронизации. Нужно седьмое.

Это состояние означает, что браузер не может достучаться до **сервера Financial AI** —
в отличие от существующего состояния «Не удалось обновить портфель», которое означает
недоступность **T-Bank API**. Обе ситуации должны быть однозначно различимы пользователем:
разные формулировки, разные иконки или цветовые акценты. Пользователь должен понимать,
где именно проблема.

Состав состояния:

- заголовок и текст, прямо называющие причину — нет связи с сервером Financial AI;
- отображаемые данные остаются видимыми и помечены как последние известные, с указанием
  их возраста и времени последней успешной синхронизации;
- индикация того, что система автоматически пытается восстановить связь;
- действие «Повторить» для немедленной попытки.

Переиспользуй существующий универсальный баннер (`bannerTitle` / `bannerText` /
`bannerAction`) — новый компонент создавать не нужно, нужен новый вариант оформления и
тексты. Учти, что индикатор `connection-status` в шапке
(«Т-Банк подключён · счёт •• 4821») относится к подключению брокера и для связи с
сервером не подходит.

## 3. Удали элементы, выведенные из объёма

Подключение брокера больше не является действием пользователя: доступ задаётся токеном в
конфигурации сервера. Удали:

- призыв к действию «Подключить Т-Банк» (`connect-broker-cta`);
- диалог подключения (`connect-broker-dialog`, `connectDialog` с «Продолжить» / «Отмена»);
- пункт меню «Отключить брокера» (`menuDisconnect`).

## 4. Переосмысли состояние «Брокер не подключён»

Состояние остаётся, но меняет смысл: оно означает, что доступ к T-Bank API **не
сконфигурирован** либо токен отклонён брокером. Действия пользователя здесь нет.

Замени призыв «Подключить Т-Банк» на спокойное пояснение, адресованное тому, кто
настраивает систему: доступ не сконфигурирован, нужно задать токен в конфигурации
сервера. Тон — информирующий, без кнопки, ведущей в никуда. Значение токена нигде не
отображается.

## 5. Проверь после правки

- Все семь состояний раздела показаны и визуально различимы: загрузка, брокер не
  подключён, портфель пуст, данные актуальны, данные устарели, ошибка синхронизации
  с брокером, нет связи с сервером.
- «Не удалось обновить портфель» и «Нет связи с сервером» невозможно перепутать.
- Настройка интервала и действующее значение интервала видны, состояние ошибки ввода
  показано.
- Ни в одном состоянии нет действий подключения и отключения брокера.
- Во всех состояниях, где показаны данные, виден их возраст и время последней успешной
  синхронизации.
- Раздел остаётся пригодным для мобильных экранов.
