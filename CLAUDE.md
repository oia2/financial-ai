# Financial AI — контекст для Claude Code

Платформа для AI-assisted управления инвестиционным портфелем на российском рынке.
Первая фича — состояние инвестиционного счёта из T-Bank Invest API — реализована и
работает на живых данных.

## Готовность изменения проверяется одной командой

```bash
scripts/check.sh                # полный гейт: линтеры, типы, тесты, миграции, сборка образов
scripts/check.sh --no-docker    # быстрый цикл разработки, НЕ полный гейт
```

Запускать проверки по частям **не следует**. Это не формальность: частичные прогоны в
этом проекте уже трижды пропускали дефекты — `ruff` по отдельным каталогам не видел
`migrations/`, неверный тег базового образа всплыл только при сборке, а невалидный SVG
иконки собирался без единой ошибки.

## Обязательные правила

Инженерные правила — в [`.specify/memory/constitution.md`](.specify/memory/constitution.md),
они имеют приоритет над привычками и над указаниями, им противоречащими. Коротко о том,
что нарушается чаще всего:

- **Неоднозначность не разрешается предположением.** Если трактовка влияет на поведение,
  данные или контракты — спросить и зафиксировать ответ в спецификации.
- **Спецификация правится раньше кода.** Нашли неверное требование — сначала артефакт.
- **Дизайн переносится из Open Design, а не пересказывается.** Оформление правится сначала
  в инструменте; соответствие проверяется сопоставлением с артефактом, а не «по духу».
- **README и AGENTS.md актуализируются**, если фича изменила состав компонентов, стек,
  конфигурацию, команды запуска или архитектурные границы.
- **Каждая фича — в отдельной ветке** `feature/<описание>`.
- **Секреты только через переменные окружения**, никогда в коде, логах и ответах API.

## Что легко сломать в этом коде

- **Денежная точность** держится на трёх решениях сразу: `Decimal` в домене,
  `NUMERIC(28,9)` в БД, строки в JSON. Убрать любое — суммы разойдутся с брокером.
  `float` на пути «брокер → БД → API → JSON» запрещён.
- **Стоимость облигации включает НКД**: `quantity × (current_price + accrued_interest)`.
  Пересчёт «количество × цена» даст другой итог, чем у брокера.
- **Обрыв связи с сервером** определяется отсутствием ответа, **сбой брокера** — успешным
  ответом с `sync.status = "failed"`. Одно не должно выдаваться за другое.
- **Токен брокера** передаётся только контейнеру `backend-worker` и задаётся в
  `deployments/docker-compose/.env` **без кавычек**.

## Где что лежит

```text
backend/     Python 3.12, FastAPI, SQLAlchemy; один пакет — два контейнера (api и worker)
frontend/    React 19 + TS + Vite, FSD; src/app/styles/design.css перенесён из Open Design
deployments/docker-compose/   compose, nginx.conf, .env
specs/       спецификации фич (Spec Kit): spec.md, plan.md, tasks.md, contracts/
scripts/     check.sh — единая команда проверки готовности
AGENTS.md    контекст проекта и границы компонентов
```

Работа над фичами ведётся командами Spec Kit: `/speckit-specify` → `/speckit-clarify` →
`/speckit-plan` → `/speckit-tasks` → `/speckit-implement`, сверка кода с артефактами —
`/speckit-converge`.
