# AGENTS.md

## Назначение

Этот файл содержит общий контекст проекта **Financial AI** для AI-агентов, работающих с репозиторием.

Обязательные инженерные правила проекта определены отдельно в:

```text
.specify/memory/constitution.md
```

Готовность изменения проверяется одной командой — запускать проверки по частям не следует:

```bash
scripts/check.sh                # полный гейт, включая сборку образов
scripts/check.sh --no-docker    # быстрый цикл разработки, НЕ полный гейт
```

Агент **ДОЛЖЕН** учитывать Constitution при спецификации, планировании и реализации любых изменений.

Конкретные требования отдельной фичи определяются её `spec.md` и `plan.md`.

## 1. Контекст проекта

Financial AI — платформа для AI-assisted управления инвестиционным портфелем и торговли на российском фондовом рынке.

Целевая цепочка системы:

```text
рыночные и справочные данные
        ↓
Daily ML
        ↓
ранжирование активов
        ↓
portfolio / target-position logic
        ↓
Intraday Execution ML
        ↓
исполнение сделок
        ↓
брокер
        ↓
ордера / сделки / позиции
        ↓
Backend / PostgreSQL / Frontend
```

Система развивается поэтапно. Наличие компонента на целевой архитектурной диаграмме **НЕ ОЗНАЧАЕТ**, что вся его будущая функциональность уже должна быть реализована.

Агент **НЕ ДОЛЖЕН** реализовывать будущие части системы, если они не требуются текущей спецификацией.

### Известные отступления развёртывания от диаграммы

Отступление зафиксировано здесь намеренно: диаграмма остаётся каноном, но развёртывание
от неё отличается, и это различие не должно обнаруживаться заново при каждом чтении.
Протокол обращения к T-Bank на диаграмме приведён к фактическому — gRPC.

| Диаграмма | Развёртывание | Причина |
|---|---|---|
| `Nginx` — отдельный контейнер | nginx работает внутри образа `frontend` (multi-stage: сборка Node → runtime `nginx:alpine`) | перед единственным SPA второй проксирующий слой добавляет сервис и volume, не давая ничего. Решение владельца проекта от 2026-08-26. Разделение вернётся, когда за nginx появится больше одного upstream'а |

Диаграмма содержит встроенную модель drawio (`content="<mxfile…"`), поэтому правится
только в draw.io: правка текста в SVG мимо модели будет потеряна при следующем открытии.

Текущая архитектура включает следующие основные компоненты:

```text
Frontend        — React-приложение; nginx внутри того же контейнера отдаёт статику
                  и проксирует /api, отдельного сервиса nginx в развёртывании нет

Backend-API     — публичный HTTP API; к T-Bank НЕ обращается

Backend-Worker  — синхронизация с T-Bank Invest API; единственный сервис,
                  которому передаётся токен брокера

PostgreSQL      — состояние счёта, статус синхронизации, настройки

Daily ML             — на целевой диаграмме, ещё не реализован
Intraday Execution ML — на целевой диаграмме, ещё не реализован

T-Bank API      — внешняя система
MOEX            — внешняя система
```

Архитектурная диаграмма определяет основные границы ответственности системы, но не должна использоваться как основание для преждевременной реализации ещё не требуемой функциональности.
